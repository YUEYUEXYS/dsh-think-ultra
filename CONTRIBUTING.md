# Feedback & Reports

dsh-think-ultra is distributed **only as a hardened, obfuscated build**; the
underlying source, build pipeline and obfuscation toolchain are private and are
not published.

## Issues are welcome

Field reports genuinely help. When opening an issue, please include:

- the delivered build version (from `package.json`)
- OS, Node version and DeepSeek Harness version
- which model surface was active (Flash / Vision / Pro) and the Ultra state
- clear steps to reproduce, expected vs. actual behaviour, and a screenshot
  where useful

## Pull requests

Because no source is published, ordinary source pull requests cannot be
accepted. Submissions whose purpose or effect is to deobfuscate, decrypt,
decompile, reconstruct, re-host, or rebrand the protected artefact are
expressly prohibited by the [LICENSE](LICENSE) and will be closed.

Commercial use, service offerings and integrations built *around* the delivered
build are welcomed — see the licence for the exact boundary.
